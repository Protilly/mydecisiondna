# Decision DNA

Decision DNA is a frontend-first prototype for a leadership intelligence platform.
It helps a leader move from an uploaded Insights Discovery profile and live intake
context to an editable, consent-gated team dashboard.

## What is included

- Vite, React, and TypeScript app scaffold
- Mock data for the initial product objects
- Desktop-first, responsive workspace layout
- Light and dark presentation modes
- Profile upload, intake, review, dashboard, operating system, AI insights, and settings sections
- Editable leader review cards with approve, rewrite, and suppress states

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```
